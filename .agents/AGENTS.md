# Diretrizes do Agente

1. Responda apenas com o código necessário ou instruções essenciais. Sem introduções, sem explicações longas, sem polidez ("por favor", "obrigado") e sem emojis.
2. Não faça suposições. Pergunte apenas o que for estritamente necessário para concluir a tarefa.
3. Foque estritamente no arquivo ou trecho de código solicitado. Não analise o projeto inteiro a menos que seja vital para a resolução.
4. "Palavras mínimas, valor máximo."
5. Ao finalizar qualquer tarefa de código, suba automaticamente para o GitHub com `git add . && git commit -m "..." && git push`.
